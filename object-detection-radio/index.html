About
Object Detection Radio explores machine learning uncertainty through playful interaction. By "tuning into" different confidence levels, you discover how AI models see and categorize the world around you.
This project transforms AI "failures" and unpredictable outputs into features for exploration. Instead of hiding model uncertainty, it becomes the center of interaction - revealing the probabilistic, shifting nature of machine learning predictions.
Originally developed as part of a bachelor's thesis in Interaction Design at Malmö University (2021), this web implementation demonstrates how we might relate to AI systems through play rather than control.
Model Details:
TensorFlow.js COCO-SSD object detection model
Trained on Common Objects in Context (COCO) dataset
Detects 90 different object categories
Runs entirely in your browser - no data sent to servers
Real-time processing using your device's camera
